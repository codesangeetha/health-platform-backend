# Health Platform Backend

A comprehensive health management platform backend built with Node.js, TypeScript, and MongoDB following clean architecture principles.

## Features

- **User Authentication**: Patient, Doctor, and Admin registration and login
- **Appointment Management**: Book, reschedule, and cancel appointments
- **Pharmacy Module**: Order medicines and manage prescriptions
- **Laboratory Module**: Book lab tests and access reports
- **Video Consultation**: Secure video consultation sessions
- **Payment Processing**: Integrated payment system
- **Notification System**: Real-time notifications

## Tech Stack

- **Backend**: Node.js, Express.js, TypeScript
- **Database**: MongoDB with Mongoose
- **Authentication**: JWT (JSON Web Tokens)
- **Validation**: Custom validators
- **Architecture**: Clean Architecture with Domain-Driven Design
- **Testing**: Jest with TypeScript
